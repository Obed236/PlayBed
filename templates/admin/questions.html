Fonctionnement

Les questions d’origine restent dans les fichiers JSON du projet, mais toute modification faite ici est enregistrée en PostgreSQL et prend le dessus automatiquement.

Tu peux donc modifier, désactiver ou réinitialiser une question d’origine sans modifier GitHub à la main.

Une réinitialisation efface uniquement la modification admin et remet la version JSON d’origine.
