PLAYBED DEVELOPERS

Préparer PlayBed à accueillir plus de jeux.

Cette première version pose les bases d’un futur écosystème développeur. L’objectif est de permettre à terme à des créateurs externes de proposer des jeux web compatibles avec PlayBed sans avoir accès au cœur de la plateforme.

API

Catalogue public

L’endpoint /api/v1/games expose le catalogue actuel en JSON : nom, catégorie, description et liens de lancement.

SCORES

Contrat futur

La prochaine étape du SDK consistera à fournir un contrat sécurisé pour démarrer une partie, enregistrer un score et associer des succès.

VALIDATION

Jeux contrôlés

Les jeux externes devront respecter des critères de performance, sécurité, accessibilité mobile et compatibilité avec les règles PlayBed.

Vision du SDK PlayBed

Le SDK n’est pas encore ouvert aux soumissions publiques. Cette page documente la direction technique afin que l’architecture reste cohérente dès maintenant.

PlayBed.startGame()
PlayBed.submitScore(1250)
PlayBed.unlockAchievement("expert")
PlayBed.gameOver()

Avant d’activer ces méthodes pour des jeux tiers, PlayBed devra ajouter l’authentification des applications, la validation côté serveur des scores et une procédure de modération.

API disponible maintenant : /api/v1/games
