PLAYBED DEVELOPER

Construire les prochains jeux de PlayBed.

PlayBed prépare une couche développeur pour accueillir à terme des jeux web externes tout en gardant une expérience rapide, sûre et cohérente pour les joueurs.

SDK client expérimental v0.1

⚡ Web d’abord

Les jeux doivent démarrer rapidement dans un navigateur moderne, fonctionner sur mobile et éviter les téléchargements lourds.

🏆 Scores vérifiables

Les scores destinés aux classements doivent être validés côté serveur ou via une intégration approuvée afin de limiter la triche.

🧩 Intégration simple

Le SDK client expérimental normalise déjà les événements de démarrage, de télémétrie et de fin de partie.

SDK client disponible dans la plateforme

L’objet JavaScript window.PlayBed expose une première API de télémétrie. Elle permet de tester le contrat d’intégration sans donner à un navigateur la possibilité d’écrire directement dans les classements.

PlayBed.startGame({ game: "mon_jeu" });
PlayBed.track("level_complete", { level: 3 });
PlayBed.gameOver({ game: "mon_jeu", score: 1250 });

Important : submitScore() reste volontairement fermé. Un score classé ne doit jamais être accepté simplement parce qu’un navigateur affirme l’avoir obtenu.

Ce qu’il reste avant l’ouverture externe

Une intégration publique complète nécessitera l’enregistrement des jeux, des identifiants d’intégration, une validation côté serveur et une procédure de revue avant publication. Cette couche n’est pas encore ouverte aux soumissions automatiques.

Critères de qualité

  • interface responsive et jouable au tactile ;
  • chargement rapide et ressources optimisées ;
  • aucun contenu trompeur ou mécanisme forçant un clic publicitaire ;
  • règles compréhensibles et score cohérent ;
  • respect de la vie privée et des règles de la plateforme ;
  • mécanisme de score compatible avec une validation serveur.
